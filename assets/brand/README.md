# nosey / Classic+ Mono

Approved concept: Mono. A terminal-native lowercase wordmark with a three-character face, `:^)`.

## Quick start

- `svg/horizontal/nosey-horizontal-for-dark.svg`: primary logo on Ground.
- `svg/horizontal/nosey-horizontal-for-light.svg`: primary logo on Parchment.
- `svg/mark/`: standalone and small-size marks.
- `svg/stacked/`: narrow-space lockup.
- `svg/wordmark/`: wordmark only.
- `png/`: high-resolution versions (transparent or pre-composited as named).
- `icons/`: dark/light/amber square, rounded and upright icon variants.
- `web/`: favicon SVG, PNG, ICO, Apple touch icon, PWA icons, manifest and head snippet.
- `social/`: 1280×640 and 2560×1280 repository/social cover.
- `terminal/`: plain ASCII and ANSI truecolour versions.
- `tokens/`: CSS and JSON values.
- `guidelines.pdf`: visual identity reference.

## Handoff notes
The colour palette matches the uploaded source assets exactly. The wordmark and punctuation are custom SVG outlines rebuilt from the chosen raster concept, not an exact vector trace or a commercial font. SVGs contain no live text or embedded raster artwork. The horizontal mark is the primary identity; an upright face is a secondary avatar option from the original icon convention. The light accent uses ochre to preserve contrast. This is a proposed production geometry; final trademark clearance, live integration and platform submission checks are not performed.

## Colour
Ground #14100A; Parchment #F5E6C8; Nose #FFB000; Nose on light #8A5A00.
Contrast (WCAG relative luminance): Parchment/Ground 15.37:1; Nose/Ground 10.34:1; Ochre/Parchment 4.81:1.

## Size and spacing
Reserve at least one eye diameter around the lockup. Use horizontal logo at ≥144 px width, mark at ≥24 px width, and the pixel-hinted favicon for 16 px. These are design recommendations based on rendered size checks, not platform-specific certification. Use the transparent masters on appropriate backgrounds; opaque assets are already padded. Avoid stretching, shadows, recolouring, moving the nose, or adding letters to the icon.
