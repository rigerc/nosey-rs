# Validation

- SVG audit: primary mark and small-size mark report no issues; horizontal lockup flagged only for width. Stacked and standalone alternatives supplied.
- All SVGs parsed and contain no live text, raster images or filters.
- PNGs decoded and verified; ICOs contain 16, 32 and 48 px entries.
- Raster preview inspected and 16 px favicon strengthened using a pixel-grid cut.
- Colour ratios computed from original palette values.
- Trademark review, actual integration in Nosey, and device-specific platform checks remain outside this package.
